Project Title: Multi-Agent Smart Bricks: A Sensor-Based Modular Interactive System

Project Statement:
	
Design a set of electronic bricks that communicate with neighbouring bricks
and change their behaviour depending on how they are assembled. The first
step can be communicated to count presence within a range (for the suggested
use case scenario).

Each brick is an autonomous agent that:
• Detects neighboring bricks
• Exchanges information (it can be a code for an action)
• Makes local decisions (sense the surroundings and make decisions)
• Contributes to the overall system behavior

Instead of one controller controlling everything, every brick has its own
Microcontroller.

Futuristic use case: surgical table where all the instruments communicate with
each other to ensure every instrument is accounted for as per requirement.
